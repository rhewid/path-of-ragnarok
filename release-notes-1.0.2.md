# Path of Ragnarok 1.0.2

The default keystone limit is now **2** instead of 3.

## Changed

- Setting "Most keystones a character can take": default 2 (was 3). Still adjustable from 0 (no limit) to 12.

## Notes

- If you saved your own value for this setting it is kept. Characters that already have more keystones than the limit keep them but cannot add another.
- Copy the mod folder over, press **Apply** and restart the client.
